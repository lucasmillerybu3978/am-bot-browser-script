## About the Project

am-bot is a compact HTML-based tool for automating actions in a web browser. Its design emphasizes browser workflows and repeated page interactions while avoiding the need for a large or complex runtime environment.

The repository provides a straightforward base for web automation projects. Because it uses HTML as its primary platform, it can be adapted into browser-driven helpers, small task utilities, or interface experiments where the automation behavior is the main focus.
